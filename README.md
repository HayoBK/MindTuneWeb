# MindTuneWeb

Sitio público de MindTune (https://mindtune.cl), app de terapia sonora para tinnitus.
Hugo extended 0.162.1 autocontenido, publicado con Cloudflare Pages desde `main`.

- Contexto y reglas: `CLAUDE.md`
- Publicación paso a paso: `GUIA-DEPLOY-MINDTUNEWEB.md`
- Bitácora: `CONTINUACION-MINDTUNEWEB.md`

Build local: `HUGO_ENVIRONMENT=production hugo --minify --gc` · Previsualizar: `hugo server -D`
